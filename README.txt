SMARTBUDGET – TRABAJO FINAL MÓDULO 3
----------------------------------

Este proyecto corresponde al trabajo final del Módulo 3 del curso Front-End.

SmartBudget es una landing page de una aplicación web que permite a los usuarios
visualizar y gestionar sus finanzas personales de forma simple e intuitiva.

El objetivo del proyecto es aplicar los contenidos vistos en clases,
principalmente Bootstrap 4 y el uso de Sass para organizar los estilos.

----------------------------------
TECNOLOGÍAS UTILIZADAS
----------------------------------

- HTML5
- Bootstrap 4.6.2
- Sass (SCSS)
- Bootstrap Icons
- JavaScript (solo para Bootstrap)
- Git y GitHub

----------------------------------
ESTRUCTURA DEL PROYECTO
----------------------------------

- index.html
- assets/
  - css/
    - main.css (archivo compilado desde Sass)
  - scss/
    - abstracts/
    - base/
    - components/
    - layout/
  - img/
- package.json
- .gitignore
- README.txt

----------------------------------
CARACTERÍSTICAS DEL PROYECTO
----------------------------------

- Navbar responsiva con Bootstrap
- Sección Hero con llamado a la acción
- Sección de características usando Cards de Bootstrap
- Uso de Sass modularizado por componentes y layout
- Footer completo con enlaces y formulario
- Diseño responsivo para mobile, tablet y desktop

----------------------------------
SASS
----------------------------------

Los estilos están desarrollados utilizando Sass y organizados en distintos
archivos para facilitar la mantención del código.

El archivo principal es:
assets/scss/main.scss

Para compilar los estilos se utiliza el comando:

npm run sass:build
